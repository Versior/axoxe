# 社区与致谢

AXOXE 的问题反馈和功能建议统一提交到 [GitHub Issues](https://github.com/Versior/axoxe/issues)。附上版本、部署方式和复现步骤。日志与截图中不要包含凭据。

代码和文档修改通过 [Pull Request](https://github.com/Versior/axoxe/pulls) 参与。参见 [开发指南](/zh/docs/dev/guide) 和 [CONTRIBUTING](https://github.com/Versior/axoxe/blob/main/CONTRIBUTING.md)。
